Cairn Source code
Runs on your own computer

Stop telling every AI tool the same things about your work.

Cairn keeps the background you keep repeating — your projects, decisions, and preferences — in one private place you control, and lets the AI tools you authorize look up only the parts they need.

Try it in about a minute

No account, no API key, and nothing to install beyond Node and pnpm. 

git clone https://github.com/johnmontejano/cairn
cd cairn
pnpm install && pnpm setup
pnpm demo:seed && pnpm dev

Read the source

This page is a shop window, not the product. Cairn needs a database and a server, so it cannot run on GitHub Pages — it runs on your machine, where your memory stays.

Three steps, then it gets out of your way

There is nothing to configure and nothing to learn first. You can be looking at your own memory in about a minute.

  1. Add whatever you keep repeating

    Paste a note, drop in a document, or point at a page. Nothing needs to be tidy first.

  2. Look at what it found

    Each thing worth remembering arrives as a card with the sentence it came from. Keep it, reword it, or throw it away.

  3. Stop explaining yourself

    Ask questions here, or let a tool you already use look things up. You decide which, and you can change your mind.

Every answer shows its receipts

A confident answer you cannot check is worse than no answer. So every statement points back to the exact sentence it came from, in the document it came from, on the day it arrived.

The same is true of every saved memory: open “Why do you know this?” on any card and the original words are right there.

You keep hold of it

This is where a lot of your working life ends up. That deserves saying plainly rather than in a policy nobody reads.

  • It stays yours

    Everything you keep is ordinary Markdown you can download in one click, and delete in one step. No export request, no waiting.

  • Nothing is saved behind your back

    Every memory waits for you to keep it. Nothing reaches an AI tool until you connect one, and turning it off takes effect immediately.

  • It will tell you when it does not know

    Answers can only use what you saved. When there is not enough, it says so instead of guessing.

What this is not

Worth stating up front, since most project pages do not.

  • Not deployed

    There is no hosted version. It runs locally, and the deployment guide in the repository explains what hosting it would involve.

  • Not end-to-end encrypted

    Your memory is encrypted at rest with a key per workspace, but the server unwraps it to do its work. The threat model in the repository says exactly what that protects and what it does not.

  • Not independently reviewed

    No security audit has been done, and no compliance certification is claimed.
